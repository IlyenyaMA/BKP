# BKP
Программный код на языке С для управления сборочным роботом с системой технического зрения
## О проекте

Выпускная квалификационная работа выполнена на реальном сборочном роботе на кафедре университета с использованием специализированного ПО Automation Studio.  
Цель работы — автоматическая сортировка трёх колец разного размера и сборка из них пирамиды в порядке от большего к меньшему.

Кольца подаются в случайном порядке и перемещаются по подвижному конвейеру. Датчики фиксируют появление объекта, камера распознаёт кольцо, после чего робот выполняет сортировку. Для временного размещения колец используются два резервных пустых места — это позволяет корректно собрать пирамиду даже в случае, когда наибольшее кольцо приезжает последним.

## Задача

- Имеется 3 кольца разного диаметра.
- Кольца подаются в случайном порядке.
- Кольца движутся по подвижному конвейеру.
- Датчики определяют появление объекта.
- Камера распознаёт объект.
- Робот должен собрать пирамиду: снизу — большее кольцо, сверху — меньшее.
- Для промежуточного хранения доступны 2 резервных пустых места.

## Принцип работы

1. Датчик фиксирует появление кольца на конвейере.
2. Камера распознаёт кольцо и определяет его размер/класс.
3. Контроллер принимает решение: поставить кольцо сразу в целевую пирамиду или временно переместить в резервную позицию.
4. Робот захватывает кольцо и перемещает его в нужную точку.
5. Если большее кольцо приходит последним, меньшие кольца временно переставляются в два резервных места.
6. После этого собирается финальная пирамида в правильном порядке — от большего к меньшему.
7. Цикл повторяется до завершения сортировки.
